# データの扱い

## Macに保存するもの

原文と編集履歴、画像、カテゴリ、AI出力、Good／Badと訂正、検索用キャッシュ、下書き・設定をローカルのSQLiteへ保存します。Electronには別途ブラウザ保存領域・Cookie・キャッシュがあり、これらも公開リポジトリに含めません。

ローカル保存はアプリ独自の暗号化を意味しません。Macのユーザー権限・ディスク保護と、書き出したバックアップの管理が必要です。保存先は [開発手順](development.md) を参照してください。

## AIへ送るもの

選択したモデルへの処理はCodex CLIを通じて行います。対象の原文の本文・版ID・日付・出典区分・元URLを送ります。メモにURLがあり、リンク先の本文を読み取れている場合は、その本文（1回の処理で合計約3万6千文字まで）も外部の資料として送ります。クイック入力で取り込んだ引用（excerpt）も送ります。処理に応じて既存カテゴリ情報、Askの質問、過去の評価・理由・訂正コメントも入力になります。現在の解析経路は画像の内容をAIへ送りません。

保存後の自動分類は初期設定で有効です。カテゴリとモデルが利用可能なとき、対象のメモを分類します。カテゴリまとめの自動更新とDigestを併用するAsk検索は初期設定では無効です。設定で動作を変更できます。

接続先によるデータの扱いと利用枠は利用するサービス・アカウントの条件に従います。アプリは認証情報をソースへ埋め込まず、CLI側の認証を使用します。推論経路全体の隔離は検証中で、プロンプトの「ツールを使わない」という指示だけで保証するものではありません。

## AI解析対象外のメモ

保存前の入力画面、または保存後の詳細画面から対象外にできます。対象外の原文は分類・まとめ・Ask候補・埋め込みから除きます。送信前と返却後に入力を確認し、影響する処理を中断します。

対象外へ変更する前に送信した内容は取り消せません。既存のAI出力や評価はローカルに残り得ますが、その依存先を追跡して後のAI入力から除外します。対象に戻しても、除外済みの過去の出力を自動で再利用しません。

メモは引き続き一覧、文字検索、カテゴリ、Graphでローカルに表示できます。

## AI以外の通信

- 保存した公開URLは、リンク先へHTTPリクエストを送り、タイトル・説明・本文（最大2万文字）を読み取ってこのMacに保存します。JavaScriptは実行しないため、JavaScriptで表示するページの本文は読み取れません。リンク先の取得はAI解析対象外の設定とは別に動作しますが、対象外にしたメモの本文はAIへ送りません。YouTubeのページでは、ページに含まれる動画の概要欄・チャンネル名・「音楽」欄の曲名とアーティストを読み取ります。
- 自動分類がオンのとき、保存したメモは（カテゴリがなくても）数件ずつCodexへ送り、カテゴリ分けと、メモから分かること（好き・したい・したことなど）を原文の引用つきで読み取り、このMacに保存します。既にあるメモも、モデルが選ばれたときに一度だけ同じように読みます。メモをAI解析の対象外にするか削除すると、読み取った内容は削除されます。
- 読み取った内容から、トピックごとの短いプロフィール（例:「SUITSを5周するほど見ている」と、続いているか過去か）を作り、このMacに保存します。作成・更新のため、読み取った内容と関係するメモをCodex（またはClaude Code）へ送ります。元のメモを削除するかAI解析の対象外にすると、そのメモを使った行はすぐ削除されます。
- まとめと質問は、保存前に回答を引用元のメモと照らし合わせるため、回答と引用元のメモをもう一度Codexへ送ります。
- 自動分類がオンのとき、リンク付きのメモはリンク先が何か（種類・作品名・作者・「後で聞く」などのメモの指示・短い要約）を読み取ってこのMacに保存します。作品名と作者は、リンク先の資料かメモに実際に書かれているものだけを残します。メモをAI解析の対象外にすると、この読み取り結果は削除されます。
- 現在のUIはGoogle Fontsからフォントを読み込みます。メモ本文をフォント要求に付けませんが、通常の外部リソース取得が発生します。
- 導入前からあるメモが300件を超えるときは、AIで読み込む前に、全部・最近1年だけ・あとでのどれにするかを確認します。選ぶまでは送りません。
- AIの使用量の表示のため、Codex にはアカウントの使用率（5時間・週）を問い合わせます（メモは送りません）。Claude Code は処理の応答に含まれる使用率を保存して表示します。pure. 自身の使用量は、このMacの処理記録（処理の種類・時間・トークン数。メモや回答の内容は含まない）から集計します。
- ニュースの「集める」（またはオンにしたときの毎日1回）では、まずまとめや質問と同じく、AI解析の対象のメモ（最大72件）をCodexへ送り、具体的な関心と根拠の引用を受け取ってこのMacに保存します。メモが前回から変わっていなければ送りません。関心が見つかったときは、関心の名前とその理由（メモや引用は含めない）を接続先の AI へ送り、「それが好きなら気になりそう」な関連の言葉を最大4つ受け取ります。次に、見つかった関心の言葉・関連の言葉とその英語名（どれも画面の「送る言葉」に表示し、外したものは除く）と自分で足した言葉だけを、Google ニュース、Hacker News（Algolia）、接続先の AI の Web 検索（Codex なら OpenAI、Claude Code なら Anthropic）へ送ります。Web 検索の依頼には、メモではなくこの言葉だけを渡します。メモの本文は送りません。検索で見つかったリンクの確認のため、そのページ（Reddit は oEmbed）へリクエストを送ります。集めた記事が本当にその関心の記事か（名前が出てくるだけ・同名の別物でないか）を確かめるため、見出し・出典・関心の言葉とその理由を接続先の AI へ送ります。見出しの翻訳のため、集めた見出しを接続先の AI へ送ります。集めた記事はこのMacに14日間保存します。メモを完全に削除するかAI解析の対象外にすると、そのメモからの引用は削除されます。
- AIの接続先に Claude Code を選んだ場合は、Codex と同じ内容を Claude Code（Anthropic）へ送ります。Claude Code の会話は保存しない設定で呼び、Claude Code 側の設定ファイルやMCPサーバーは読みません。
- pureはCodexを専用のフォルダで動かし、個人のCodex設定（指示ファイル・フック・MCPサーバー）を読みません。サインイン情報は、pure側になければ `~/.codex/auth.json` をこのMac内で一度だけ写します。Codexにはメモ内容の会話記録を残さない設定（ephemeral）で依頼しています。
- AIの呼び出しごとに、処理の種類・モデル・時間・トークン数・成否をこのMacに記録します（最新2000件）。プロンプトや回答の本文は記録しません。
- CodexのWeb検索は、ニュースの収集でだけ有効にします。分類・まとめ・質問などの処理では無効にしているため、メモの内容をもとにWeb検索することはありません。
- ログインやユーザーが開くリンクは外部ブラウザを使用します。

## ごみ箱・完全削除・バックアップ

ごみ箱では原文を保持し、復元できます。完全削除は現行DB内の原文・画像と関連する解析等を削除し、SQLiteの削除領域整理を実行します。同じMacでは削除済みIDを記録し、それを復活させるバックアップの復元を拒否します。

管理バックアップは設定で監査し、選択して削除できます。外部に書き出したバックアップや他端末のコピーは自動で消えません。ディスク、OSバックアップ、接続先に残るコピーの物理的な消去を保証しません。

バックアップや不具合報告には原文、評価、AI出力が含まれる可能性があります。公開の報告には架空のメモを使用してください。
